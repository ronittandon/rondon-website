# RONDON marketing website

Responsive single-page static website using RONDON's Midnight Navy (#0B1220), Champagne Gold (#C9A86A), and Off-White (#F5F3EE).

## Before publishing
1. In `index.html`, replace `mailto:REPLACE-WITH-YOUR-EMAIL` with your real business email.
2. Confirm the PR demo URL is still `https://rondon-real-estate.vercel.app/pr-demo`.
3. Review all copy and disclaimers before sharing publicly.

## Preview
Open `index.html` in a browser.

## Deploy
Import this folder/repository into Vercel as a static site. It requires no environment variables or Supabase connection and does not modify the existing PR demo.
